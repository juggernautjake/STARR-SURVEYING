### ▶ The finding that ties three of them together: the check was designed right and detected wrong

Not "no check". Not "wrong rule". **The right rule, wired to a signal that cannot fire.** Three
independent instances in one evening:

1. **F1b tested `error.code === '42P01'`** — correct for Postgres, which is what answers a missing
   relation that way. We do not talk to Postgres. PostgREST rejects the table name against its schema
   cache first and answers **`PGRST205`**, so the branch was unreachable and its careful message would
   have surfaced as a raw schema-cache string in a 500. Found by asking the live database one
   question instead of reasoning about it.
2. **R4b's spend ratchet matched prose.** `REPORTS_SPEND` searched the whole file, so a comment
   mentioning `infra/usage` credited a file as migrated — including, potentially, one whose comment
   said it does *not* use it.
3. **Two negative controls reported false green**, both my own fault rather than the guard's: one
   replaced an import with a local stub *of the same name*, one left a call behind. `grep` after each
   attempt is what showed it — the rule §7 added this morning, paying for itself twice more.

The common shape: **a check that reads as though it works.** Nothing fails, nothing logs, and the
code says the right thing in English. It is strictly harder to see than a missing check, because a
missing check leaves an obvious hole and this leaves a green tick.

The one defence that worked every time was **running the thing against reality** — one HTTP call to
the live PostgREST, one `grep` of the file after the control, one differential test putting two
implementations in the same room. None of it is clever. All of it is cheap.

### ▶ Also worth carrying: S19a's argument for splitting the big file

`CanvasViewport.tsx` was 15,494 lines, and the reason to split it turned out **not** to be size.
FILLET and CHAMFER each exist twice — `operations.ts` computes the corner *and commits it*, so it
cannot be called for a hover preview — and neither implementation had a single test, because both
previews were private functions inside a `'use client'` component. **Geometry a surveyor relies on,
checked by nothing, because it was unreachable.** 158 lines out, twelve tests in.

The two are now pinned to each other by a differential test that asserts they agree on the **refusal**
as well as the answer: a preview that refuses a corner the commit would cut is invisible — nothing
errors, the cursor simply never shows a preview and the surveyor concludes it cannot be done.
