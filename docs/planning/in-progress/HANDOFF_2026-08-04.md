**S13 is the one to remember.** The bug was *already known and already fixed — in the wrong places.*
`newDocument()` carries a comment describing this exact orphaning; the fix went there and to
`loadDocument`, and **not to the initial state**, which is the path that runs when you simply open the
editor. It survived because every test called `newDocument()` first — testing its way *around* the
broken path.

**And the first fix for it was wrong**, caught by the owner: it seeded `layerOrder[0]`, which is
`SURVEY-INFO`, the reserved title-block layer. The rule is not "always have an active layer" but
**never create geometry the surveyor cannot see, and never choose the layer for them.**

### ▶ Three of the day's six defects were introduced by the day's own work

Worth stating plainly, because the pattern is not "old code was wrong":

1. **S19 locked employees out of filing receipts** (fixed in W6c). It gated `/admin/receipts/new`
   with the nav registry's seven roles, which omit `employee` — the role middleware itself falls back
   to. The upload API checks only that a session exists. **The gate was stricter than the boundary it
   was shadowing**, which is the exact mistake S19's own commit message describes avoiding, made one
   level down inside the entry written to prevent it. Found by driving the app, not by review.
2. **S-9b's first import failed the production build** while `tsc`, 1,497 worker tests and 969
   research tests passed. Making the import lazy did **not** help — webpack walks dynamic imports
   when building the graph.
3. **S16b's first draft put the new field on the wrong interface** (`DisplayPreferences`, which
   happens to carry `originNorthing`) and reworded a LandXML string that had to stay byte-identical.

### ▶ What each one is now guarded by

Every guard below was **watched failing** before it was kept, and two negative controls silently did
not run at all (a `perl` that hit CRLF; a `python` that is not installed) and reported false green
until they were redone with a real edit.

- `__tests__/middleware/admin-route-gates.test.ts` — every `/admin` page is gated or knowingly open;
  specific prefixes precede general ones (*the file said so in a comment, and a comment cannot fail*);
  **no nav link is shown to a role its own gate would bounce** (this is what caught defect 1); and
  Capture Receipt admits every role in `ALL_ROLES`, checked against the constant, not a copy.
- `__tests__/research/worker-imports-stay-bundleable.test.ts` — walks the import graph from every
  `@/worker/...` module the app imports and fails if one reaches `services/pipeline.ts`. **8 ms
  instead of a five-minute build**, and it prints the path.
- `__tests__/cad/delivery/declared-zone-in-exports.test.ts` — pins the *no-declaration* case as whole
  strings. A test that only checked "declaring a zone changes the output" would have passed while
  silently relabelling every historical drawing on its next export.
