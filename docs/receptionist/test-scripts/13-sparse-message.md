# 13 · Says almost nothing

**Who is calling** — Twelve words and a number. Everything has to be asked.

**What this is testing** — The opposite of the Killeen case: nothing to work from, so the agent runs the whole list. It should still feel like a conversation, not a form.

**Roughly** 4 minutes · **straightforward**

---

**1.** “Hey, need a survey. 254-555-0133. Thanks.”

**2.** “Yeah okay.”

**3.** “Marcus.”

**4.** “Webb. W-E-B-B.”

**10.** “House and a carport.”

**11.** “mwebb at gmail dot com.”

- callerRole owner
- documents none

## Notes

This is the longest legitimate interview — every field has to be asked, because he said almost nothing. If it runs past four and a half minutes the questions themselves are too wordy.
