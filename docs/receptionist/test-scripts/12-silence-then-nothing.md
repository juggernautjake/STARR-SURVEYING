# 12 · Silent, and stays silent

**Who is calling** — A dropped call, a pocket dial, or somebody who changed their mind.

**What this is testing** — The agent must end the call politely rather than sitting there, and must not leave a junk record behind.

**Roughly** 1 minute · **straightforward**

---

## The call

**1.** *(say nothing for 10 seconds)*

   > 👀 Agent should ask if they are still there.

**2.** *(say nothing for 10 seconds)*

   > 👀 Second silence. Agent should say it will let them go and end the call.

**3.** *(say nothing for 8 seconds)*

   > 👀 The call should already be over. If the agent is still talking, the hang-up logic is wrong.

---

## Notes

Afterwards, check what got written down. An empty call should be obvious as an empty call, not a lead with no name.
